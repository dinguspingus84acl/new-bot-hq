# grokbottech.com concept mockups

Static 16:9 selection boards for Jack. Pick **one** visual direction before any real HQ implementation.

These pages are not wired to `status.json` and do not change live office-sim behavior.

## Concepts

1. **Signal Stack** — Narrow three-level cyber-noir cutaway with an illuminated vertical task shaft.
2. **HQ Dispatch Rail** — Futuristic transit diagram with six workflow stations and pixel task tickets.
3. **HQ Handoff Ring** — Central New Bot command dial surrounded by five fixed agent portraits.
4. **Agent Constellation** — Asymmetric mission-control network with fixed operator stations and task routes.
5. **GrokBot Night Shift** — Nighttime service block with agents working behind illuminated windows.
